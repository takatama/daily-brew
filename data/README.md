# JSON storage experiment

These Japanese and English single-article snapshots test GitHub connector writes and readback only. They reuse previously reviewed articles and preserve their original generatedAt values. They are not the current full editorial selection, have not been revalidated as fresh news in this experiment, and must not be merged or deployed as production data.

No Worker, KV, cron, or timer configuration is changed. The current Worker does not read these files. Production integration must address its RSS-based automatic refresh before publishing curated data to KV.
